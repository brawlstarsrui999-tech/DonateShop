# DonateShop

Магазин донат-предметов и привилегий для Paper **1.21.11** (Java 21).

Команда **`/donshop`** (алиасы `/donateshop`, `/dshop`) открывает меню в фиолетовом стиле с двумя разделами:

- **Привилегии** (зачарованный незеритовый нагрудник) — Coal, Iron, Gold, Diamond, Emerald, Netherite
- **Предметы** (зачарованная незеритовая кирка) — супер-предметы Twix и ячейки хранения

## Цены

Валюта — **TwixCoin (tk)**, плагин **PlayerPoints**.

### Привилегии (полная цена — навсегда)

| Привилегия | Навсегда | 15 дней (50%) | 7 дней (25%) |
|---|---|---|---|
| Coal | 25 tk | 13 tk | 7 tk |
| Iron | 75 tk | 38 tk | 19 tk |
| Gold | 150 tk | 75 tk | 38 tk |
| Diamond | 300 tk | 150 tk | 75 tk |
| Emerald | 400 tk | 200 tk | 100 tk |
| Netherite | 500 tk | 250 tk | 125 tk |

Округление настраивается в `config.yml` (`price-rounding: UP / DOWN / NEAREST`), в таблице — округление вверх (UP).

**Апгрейд вечной привилегии:** владелец вечной привилегии может доплатить разницу до старшей.
Например, вечный Diamond (300 tk) → Emerald за доплату 100 tk, → Netherite за доплату 200 tk.
Временная привилегия: свою можно продлить (срок прибавляется) или выкупить навсегда;
младшую купить нельзя, пока активна старшая.

### Предметы

| Предмет | Цена |
|---|---|
| Аметистовая Кирка | 65 tk |
| Лабрис Гефеста (топор) | 45 tk |
| Фарм-Меч | 125 tk |
| Ячейка Хранения (обычная) | 120 tk |
| Улучшенная ячейка | 165 tk |
| Гибридная ячейка | 350 tk |
| Совершенная ячейка | 599 tk |

Предметы не обычные: их выдаёт плагин супер-предметов
([SuperItemsTwix](https://github.com/brawlstarsrui999-tech/SuperItemsTwix) / TwixRPGItems из EliteItems)
консольной командой `twixitems give <предмет> <ник>`. Команда выдачи каждого предмета настраивается
в `config.yml` (`give-command`). Если плагин предметов недоступен и команда не выполнилась —
TwixCoin **автоматически возвращаются** игроку.

## Зависимости на сервере

| Плагин | Зачем |
|---|---|
| **PlayerPoints** | Валюта TwixCoin (баланс, списание, возврат) |
| **LuckPerms** | Группы привилегий. Группы нужно создать один раз: `/lp creategroup coal`, `/lp creategroup iron`, `/lp creategroup gold`, `/lp creategroup diamond`, `/lp creategroup emerald`, `/lp creategroup netherite`, затем настроить префиксы/права групп |
| **TwixRPGItems / SuperItemsTwix** | Сами супер-предметы и ячейки (`/twixitems give ...`) |

Все три — `softdepend`: без PlayerPoints/LuckPerms покупки блокируются с понятным сообщением игроку, деньги не списываются.

## Как это работает

- Покупка: проверка баланса → списание через PlayerPoints → выдача → при ошибке выдачи полный возврат.
- Привилегия на срок: LuckPerms-группа выдаётся через `lp user <ник> parent addtemp <группа> <срок>`,
  навсегда — через `parent add`. Срок хранится в `plugins/DonateShop/players.yml`, по истечении
  группа снимается автоматически (проверка при входе и раз в минуту).
- Цена пересчитывается в момент подтверждения покупки — нельзя купить по устаревшей цене из открытого меню.

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/donshop` | Открыть магазин | `donateshop.use` (у всех) |
| `/donshop balance` | Баланс TwixCoin | `donateshop.use` |
| `/donshop info` | Своя привилегия и срок | `donateshop.use` |
| `/donshop setrank <ник> <ранг> [дней\|forever]` | Выдать привилегию вручную | `donateshop.admin` (OP) |
| `/donshop removerank <ник>` | Снять привилегию | `donateshop.admin` (OP) |
| `/donshop reload` | Перезагрузить конфиг | `donateshop.admin` (OP) |

Всё настраивается в `config.yml`: цены, сроки и их проценты, описания, команды выдачи, тексты сообщений (MiniMessage).

## Сборка

```bash
mvn clean package
```

Готовый плагин: `target/DonateShop-1.0.0.jar` — положить в `plugins/` сервера Paper 1.21.11.
Сборка также автоматически проверяется в GitHub Actions (вкладка Actions → артефакт `DonateShop`).
